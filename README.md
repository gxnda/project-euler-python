# Project Euler Solutions in Python

## Overview
A comprehensive collection of solutions to 59+ computational mathematics problems from Project Euler, demonstrating strong algorithmic problem-solving skills and Python programming expertise.

## Technical Highlights

### Algorithms & Techniques Implemented
- **Number Theory**: Prime number generation (Sieve of Eratosthenes), prime factorization, divisibility testing
- **Combinatorics**: Permutation generation, pandigital number validation, combination algorithms
- **Geometric Sequences**: Pythagorean triples, triangular/pentagonal/hexagonal number generators
- **String Manipulation**: Palindrome detection, string rotation algorithms, character encoding
- **Dynamic Programming**: Fibonacci sequence optimization, pathfinding through triangular arrays
- **Mathematical Optimization**: Efficient factor finding, greatest common divisor calculations

### Code Organization
- **Modular Design**: Created `util.py` library with 18+ reusable mathematical functions
- **Clean Architecture**: Separated concerns between problem solutions and utility functions
- **Type Hints**: Used Python type annotations for improved code clarity and maintainability

### Key Skills Demonstrated
- Advanced Python programming (itertools, math libraries, file I/O)
- Algorithm design and optimization
- Mathematical reasoning and problem decomposition
- Code reusability and software engineering best practices
- Performance optimization for computationally intensive problems

## Project Structure

## Notable Solutions
- **Efficient Prime Sieves**: Implemented optimized algorithms for generating large sets of prime numbers
- **Combinatorial Generators**: Built flexible permutation and rotation generators for various number bases
- **Number Property Validators**: Created validators for pandigital, palindromic, triangular, pentagonal, and hexagonal numbers
- **File Processing**: Solved problems involving parsing and analyzing text files (names, words, cipher texts)
